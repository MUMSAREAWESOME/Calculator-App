# Calculator App

This is a calculator app that will be able to use some formulas (e.g. quadratic).

This is just a small project because I got bored so dont expect anything too fancy.

## Downloads

To be able to use this *fabulous* calculator app you have two options—Install the binary or compile from soucre.

If you chose the latter refer to the build section. Otherwise, read carefully, because this is very difficult... Download the binary that is built for your OS and then run it! Difficult? I know right.

## Building

To build this project on linux you run the GCC compile comand shown below:

```bash
g++ src/main.cc -o main
```

As you know this will only work on linux so on windows you will need to modify it to build using the MINGWIN64 version of GCC, you will also need to modify the comnd so it compiles down into a '.exe' file.

```powershell
g++ src/main.cc -o main.exe
```
